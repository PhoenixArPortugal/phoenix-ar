# Phoenix AR — PHX

Site estático gratuito para a equipa Phoenix AR / Arma Reforger.

## Estrutura
- index.html
- style.css
- script.js
- assets/logo.png

## Como publicar grátis
1. Cria um repositório no GitHub.
2. Envia estes ficheiros para o repositório.
3. Em Settings > Pages, ativa o GitHub Pages a partir da branch principal.
4. O site fica acessível pelo endereço gratuito do GitHub Pages.

## Personalização
- Edita os textos diretamente no `index.html`.
- Troca as imagens da galeria em `style.css` ou adiciona imagens reais.
- O convite Discord atual está definido como https://discord.gg/2ghbnpgd2H.
